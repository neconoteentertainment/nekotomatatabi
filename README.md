# ねことまた旅

猫スタンプと一緒に旅の思い出を残す Flutter アプリです。

## 2026-09-25 旅の支出記録追加・レシートOCR廃止

- レシート画像の撮影・選択・OCR判定と関連パッケージを削除し、割り勘は完全手入力に変更しました。
- 金額・カテゴリ・日付・旅の名前・メモを保存できる「旅の支出記録」を追加しました。
- 月別の合計とカテゴリ別内訳、旅ごとの累計・明細を確認できます。
- 割り勘後の均等額または商品別の個人額を、自分の支出として登録できます。
- 和紙背景を黄色みのある新素材へ差し替えました。

## 2026-09-25 和紙デザイン適用範囲の拡張

- 和紙上の文字を濃い茶色に統一し、外側の黒背景・茶色の枠線・金茶色のボタンは維持しました。

- ホームカードに和紙背景を適用し、各メニュー名を仕様に合わせて更新しました。

## Windows

`Windowsで起動.bat` をダブルクリックしてください。

手動の場合:

```powershell
flutter pub get
flutter run -d windows
```

## macOS / iPhone

初回はプロジェクト直下で:

```bash
./setup_mac.sh
```

その後:

```bash
open ios/Runner.xcworkspace
```

XcodeでTeamを設定してiPhone実機を選択し、Runしてください。

## 補足

- データは端末内保存です。
- QR共有は旅程データそのものをQR化するため、サーバーは使用しません。
- 周辺施設検索はOpenStreetMap / Overpass系公開データを利用しています。通信状況や公開サーバーの混雑時は候補取得に失敗する場合がありますが、現在地取得後は手入力で記録できます。
