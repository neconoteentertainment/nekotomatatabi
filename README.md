# ねことまた旅

猫スタンプと一緒に旅の思い出を残す Flutter アプリです。

## 2026-10-03 Safari共有からのお気に入り登録

- Safariの共有メニューに「ねことまた旅に登録」を追加しました。
- 共有画面内でサイト名を確認・編集し、47都道府県から保存先を選べます。
- 登録したURLはApp Groups経由で本体アプリへ渡し、起動時・復帰時に既存のお気に入りへ取り込みます。

- バージョンを `0.15.0+20` に更新しました。

### 初回のiPhone実機確認

1. MacBookで `ios/Runner.xcworkspace` を開きます。
2. `Runner` と `RunnerShare` の Signing & Capabilities で、同じTeamが選択されていることを確認します。
3. 両ターゲットのApp Groupsに `group.com.neconote.nekotomatatabi` が表示されていることを確認します。
4. iPhoneへインストール後、Safariの共有ボタンから「ねことまた旅に登録」を選びます。
5. 初回に候補へ出ない場合は、共有画面の「その他」から有効にしてください。

## Windows

`Windowsで起動.bat` をダブルクリックしてください。

手動の場合:

```powershell
flutter pub get
flutter run -d windows
```

## macOS / iPhone

初回はプロジェクト直下で:

```bash
./setup_mac.sh
```

その後:

```bash
open ios/Runner.xcworkspace
```

XcodeでTeamを設定してiPhone実機を選択し、Runしてください。

## 補足

- データは端末内保存です。
- QR共有は旅程データそのものをQR化するため、サーバーは使用しません。
- 周辺施設検索はOpenStreetMap / Overpass系公開データを利用しています。通信状況や公開サーバーの混雑時は候補取得に失敗する場合がありますが、現在地取得後は手入力で記録できます。
